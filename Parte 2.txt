# 🔹 ETAPA 2 — AUTENTICAÇÃO E CONTROLE DE PERFIL

---

### ✅ 3. Tela Login

* Email
* Senha
* Botão Login

Action:
→ Sign In

---

### ✅ 4. Criar campo role no user

Na coleção users:

```
role (string)
```

Valores:

* admin
* diretor
* ti
* usuario

---

### ✅ 5. Criar redirecionamento por role

No App Start:

If currentUser.role == "diretor"
→ Dashboard Diretor

If "ti"
→ Dashboard TI

If "usuario"
→ Dashboard Usuário

If "admin"
→ Dashboard Admin

# 🔹 ETAPA 4 — MATERIAIS NA OS

---

## Tela Detalhes OS (TI)

### ✅ Botão "Adicionar Material"

Form:

* Nome material
* Quantidade
* Valor unitário

Action:

1️⃣ Create Document → os/{osId}/materiais
2️⃣ Calcular valor_total = quantidade × valor_unitario
3️⃣ Update OS:

```
status = Aguardando Aprovação de Material
```

---

# 🔹 ETAPA 5 — APROVAÇÃO DIRETOR

Tela:
Lista OS com status:

```
Aguardando Aprovação de Material
```

Botões:

🟢 Aprovar
🔴 Rejeitar

---

## Aprovar Action:

Update OS:

```
material_aprovado = true
status = Em andamento
data_aprovacao = current time
aprovado_por = currentUserReference
```

---

## Rejeitar Action:

BottomSheet com motivo obrigatório

Update OS:

```
material_aprovado = false
status = Rejeitada por Diretor
motivo_rejeicao = texto
```

---

# 🔹 ETAPA 6 — CONTROLE DE ESTOQUE

---

## Criar Tela Estoque

Listar:

```
estoque
```

Campos:

* nome_material
* quantidade_atual
* estoque_minimo

---

## Lógica na Aprovação

Quando aprovar OS:

Para cada material:

→ Update estoque

```
quantidade_atual - quantidade usada
```

→ Create movimentacoes_estoque
tipo = saida

---

# 🔹 ETAPA 7 — FINALIZAÇÃO DA OS

---

Botão visível se:

```
status == Em andamento
AND
currentUser.role == ti
```

---

Ao clicar:

1️⃣ Update:

```
status = Finalizada
finalizada_em = current time
finalizada_por = currentUserReference
```

2️⃣ Chamar Custom Action:

* Gerar PDF
* Gerar QR
* Upload Storage
* Salvar relatorio_url

---

# 🔹 ETAPA 8 — RELATÓRIO E DOWNLOAD

Na tela de detalhes:

Se status == Finalizada:

Mostrar botão:

```
Baixar Relatório
```

Action:
→ Launch URL → relatorio_url
